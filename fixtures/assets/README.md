# Asset fixtures (END_GOAL security case: "An SVG carrying script, a malformed image or font")

Hand-written, no third-party content. Used by `crates/intent-worker/tests/assets.rs`, the studio
drill and the workspace journeys.

- `hostile.svg` — every way an SVG has been used to run or load something (script elements, a
  CDATA script, a stylesheet with `@import` and `url()`, event handlers, `javascript:` and
  remote `href`s, `foreignObject`, a `data:` image, animation that sets `href`). Sanitized, only
  the shapes, the gradient, the same-document `use` and the text survive.
- `entity-bomb.svg` — a DTD with nested entities and an external entity: refused (no DTD).
- `clean-logo.svg` — a plain logo that sanitizes to itself, minus nothing.
- `not-svg.svg` — HTML with an `.svg` name: refused as not an SVG.
- `not-a-png.png` — text with a `.png` name: refused as not a PNG.

PNGs, JPEGs and fonts that must decode are generated by the tests themselves, so no binary file
of unknown origin is kept here.
